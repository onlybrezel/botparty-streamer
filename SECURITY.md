# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository instead.

Include the affected version, impact, reproduction steps and any known workaround. You should receive an initial response within seven days.

## Supported versions

Security fixes are released for the latest tagged version. Older versions may be asked to upgrade before a fix is considered.

Never include LiveKit credentials, device secrets, bearer tokens or production configuration in a report.
